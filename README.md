# 🧮 Agent Mathematics Game (C++) inspire by Gamedev.tv (added functinaltiy of lives)

A simple **text-based mathematics game** built using **C++**, where an **agent (computer)** generates math questions and the **player solves them**.  
The game checks the user’s answer and provides instant feedback.

---

## 📌 Features
- Console-based gameplay
- Agent generates random math questions
- Supports basic arithmetic operations
- Immediate answer validation
- User-friendly interface

---

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:**
  - Functions
  - Conditional statements
  - Loops
  - Random number generation
  - User input/output

---

## 🎯 Game Description
- The agent generates a math problem using:
  - Addition
  - Subtraction
  - Multiplication
  - (Optional) Division
- The player enters an answer
- The program checks whether the answer is **correct or incorrect**
